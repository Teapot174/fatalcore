Fatalcore — это устройство для разработчиков, белого хакинга/пентеста и разных проектов.

## Hardware:

- ESP32-S3: WiFi, Bluetooth, BadUSB.
- TFT 1.9
- 6 кнопок
- 1000mAh
- INA219AID
- WS2812B (RGB)
- SD card
- Infrared
- AS07 (CC1101)
- E01-2G4M27SX (NRF24)
- iButton 
- GPIO
- NFC (ST25R3916)
